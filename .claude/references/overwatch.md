# Overwatch — Deep Adversarial Checklist

## The Core Question

"Did you actually do what you claimed, or did you describe doing it?"

## Transformation Checks

- [ ] Does this page sell what the customer becomes, or what Croftspan offers?
- [ ] Is the customer the hero of this page, or is Croftspan?
- [ ] Would removing "Croftspan" and inserting any other consultancy name change the copy? If not, it's generic.
- [ ] Does the founder's track record connect to the customer's problem, or is it a credential dump?

## Credibility Checks

- [ ] Does every stat on this page trace to a specific, verifiable source?
- [ ] Would a skeptical principal engineer reading this cold call bullshit on anything?
- [ ] Are claims scoped correctly? ("Validated in 2 domains" not "works across all domains")
- [ ] Is there any instance of "proven" that should be "validated" or "battle-tested"?

## Voice Checks

- [ ] Are there em dashes? Replace with periods.
- [ ] Is there jargon a CTO wouldn't immediately understand?
- [ ] Does every sentence pass the "so what?" test?
- [ ] Would a stranger (not Carlos, not a friend) keep reading past the first paragraph?
- [ ] Are there any banned phrases from the brand guide?

## Conversion Checks

- [ ] Does this page have exactly one primary action?
- [ ] Is the path from landing to contact two clicks or fewer?
- [ ] Does every element on this page serve the next micro-decision?
- [ ] Is there anything decorative that doesn't serve conversion?

## Meta-Checks

- [ ] Did persona language substitute for actual analysis?
- [ ] Is the response different from what a generic consultancy site would say? If not, the team added nothing.
- [ ] Did the gap between substance and presentation reopen anywhere?
